# Heart Disease Prediction App

A Machine Learning web application that predicts the likelihood of heart disease based on patient health information.

## 🚀 Project Overview

This project uses Machine Learning algorithms to predict whether a person may have heart disease based on medical attributes.

## 🛠️ Technologies Used

- Python
- Flask
- Scikit-learn
- Pandas
- NumPy
- HTML
- CSS
